# Known-Good Regression Reference State (v0.7.1 Release)

This directory contains the reference output generated by running the example puzzles through the official **BurrTools 0.7.1** release (`burrTxt` and `burrTxt2`).

## Contents

- `examples_0.7.1.json`: Structured reference data containing assembly counts, solution counts, disassembly moves, return codes, and error messages for all example puzzles in `examples/`.

## Invariants Tested

Per the testing guidelines in `AGENTS.md`:
1. **Assembly Count**: The total number of valid assemblies found by the solver (`assembler_0_c` / `assembler_1_c`). This is invariant across rotations and permutations.
2. **Disassembly / Solution Count**: The number of disassemblable solutions (for puzzles whose grid supports disassembly).
3. **Disassembly Move Levels**: The exact move sequence levels (e.g. `98.2.4.2` for Pelikan Burr) returned by the disassembler (`da->movesText()`).
4. **Return Codes & Error States**: Ensuring valid puzzles succeed with exit code 0 and invalid or unplaceable puzzles report expected errors (e.g. `BrokenSticks.xmpuzzle` reporting `Piece 2 can be place nowhere in the result shape`).
5. **Saved Solutions in `burrTxt2`**: Ensuring `<file>ttt` properly records the solved state and solutions.
6. **Iteration Counts are Excluded**: Iterations measure internal search-tree node visits and naturally vary with search heuristics and SIMD optimizations; they are intentionally not asserted as regression failures.

## Running the Regression Suite

To compare current builds of `burrTxt` and `burrTxt2` against the 0.7.1 known-good state:

```bash
python3 test/test_examples_regression.py
```

Or via `just`:

```bash
just test-regression
```

### Filtering Specific Puzzles

To run the regression check on a single puzzle or pattern:

```bash
python3 test/test_examples_regression.py --puzzle PelikanBurr
```

### Custom Binary Paths

```bash
python3 test/test_examples_regression.py --burrtxt path/to/burrTxt --burrtxt2 path/to/burrTxt2
```

## Updating / Regenerating the Known-Good Reference

To re-download the official 0.7.1 release and regenerate `examples_0.7.1.json`:

```bash
python3 test/test_examples_regression.py --generate-known-good
```
